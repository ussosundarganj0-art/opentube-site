# OpenTube 🎬

**সব ধরনের ভিডিও এক জায়গায় — YouTube-স্টাইলের ভিডিও প্ল্যাটফর্ম।**

YouTube-এর পূর্ণ ক্যাটালগ (সব গান, সব ভিডিও, সব চ্যানেল) + Dailymotion + Internet Archive-এর
ফ্রি মুভি ও ডকুমেন্টারি — এক ইন্টারফেসে।

## ✨ ফিচার
- 🔍 যেকোনো গান/ভিডিও/চ্যানেল সার্চ (YouTube-এর পূর্ণ ক্যাটালগ)
- ▶️ প্লেয়ার: ৩৬০p–১০৮০p কোয়ালিটি, সাবটাইটেল, সিক/ফুলস্ক্রিন
- 🛟 কোনো ভিডিও চললে না? → সাথে সাথে অন্য সোর্সে একই ভিডিও/গান (Dailymotion + Archive.org)
- 👤 ইমেইল সাইনআপ/লগইন (Supabase) — লাইক, কমেন্ট, হিস্ট্রি, পরে দেখব, সাবস্ক্রিপশন ক্লাউডে সেভ
- 🎞️ ফ্রি মুভি (Archive.org) + বাংলা কনটেন্ট
- 📱 ট্যাবলেট-অপটিমাইজড, বাংলা/English UI, ডার্ক/লাইট

## ▶️ চালানোর নিয়ম (নিজের সার্ভারে)
```bash
docker build -t opentube .
docker run -p 7860:7860 opentube
```
অথবা সরাসরি: `node server.js` (Node 18+, Python, ffmpeg, yt-dlp লাগবে)
